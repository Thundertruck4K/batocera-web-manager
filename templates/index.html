🚀Instrucciones de uso

1. Clonar e instalar en Batocera (por SSH):

ssh root@batocera
git clone https://github.com/Thundertruck4K/batocera-web-manager.git /userdata/system/batocera_web
cd /userdata/system/batocera_web && bash install.sh

No hace falta instalar dependencias: Batocera ya trae Python 3. El instalador te pregunta si quieres añadirlo al arranque automático.

2. Arrancar el servidor (si no lo dejó ya en marcha):

python3 /userdata/system/batocera_web/app.py --port 5000

3. Abrir el manager desde cualquier dispositivo de tu red:

http://BATOCERA:5000

Funciona desde el móvil, el PC o la tele, sin mirar la IP.
