🚀Instrucciones de uso

1. Instalar dependencias en Batocera:

pip install flask pillow

2. Copiar y ejecutar el servidor:

python3 app.py

3. Acceder desde cualquier dispositivo en la red:

http://<IP-de-Batocera>:5000

4. Para ejecutar al inicio (opcional), agregar a:

/userdata/system/custom.sh

El Developer ID no es autoservicio: debes publicar un mensaje presentando la app en este foro y el equipo te asigna devid/devpassword manualmente (puede tardar días).
